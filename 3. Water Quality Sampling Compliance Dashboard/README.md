
# Water_Quality_Sampling_Compliance_Dashboard

This repository contains a Power BI project developed to improve visibility and monitoring of Water Quality Sampling Program performance. The objective of this project is to consolidate sampling information from multiple sources into a single reporting solution to support compliance monitoring, contractor management, and operational decision-making.

## Disclaimer

**Important Note:** This repository is based on an actual work project. All sensitive information has been removed or anonymised to comply with privacy and confidentiality requirements. The data and visualisations included are for demonstration purposes only and do not disclose any sensitive or proprietary information.

## Business Problem

Before this project, the Water Quality team relied heavily on spreadsheets and manually maintained files to monitor sampling activities. This created several challenges:

- Limited visibility of sampling performance
- Difficulties identifying missed or overdue samples
- Delayed contractor follow-up
- Reporting inconsistencies across different reports
- Limited understanding of performance trends over time

## Overview

A Power BI dashboard was developed to integrate sampling information from SharePoint Excel files and Microsoft SQL Server into a daily refreshed reporting solution.

The project involved not only dashboard development, but also redesigning the supporting datasets including sampling plans, sampling parameters, and location tables to improve scalability and future reporting capability.

## Data

The project consolidates information from multiple sources:

- SharePoint Excel
- Microsoft SQL Server
- Sampling Plan datasets
- Sampling Parameter datasets
- Tank / Locality / Source datasets

## Dashboard Key Information and Benefits

### Key Information Displayed on the Dashboard

* Sampling completion performance by period
* Sampling performance by frequency
* Performance by location
* Outstanding and missed samples
* Historical program trends

### Benefits of the Dashboard

* Daily visibility of sampling program performance
* Faster identification of missing samples and contractor follow-up requirements
* Improved consistency across reporting outputs
* Created a more structured and scalable reporting approach

## Key Findings & Outcomes

### Christmas Sampling Gap

The dashboard identified a significant reduction in sample collection during Christmas holiday periods. This highlighted a potential compliance risk and prompted discussions with contractors to improve future planning.

### Missing Sample Locations

The dashboard identified locations that consistently had missing samples. Investigation found that some sample locations had not been communicated correctly to contractors, resulting in updates to the sampling list.
