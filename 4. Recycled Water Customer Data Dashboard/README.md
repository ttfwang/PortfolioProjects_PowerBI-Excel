
# Recycled_Water_Customer_Data_Management

This repository contains a Power BI and data management project focused on improving how commercial recycled water customer information is collected, managed and reported.

## Disclaimer

**Important Note:** This repository is based on an actual work project. All sensitive information has been removed or anonymised to comply with privacy and confidentiality requirements. The data and visualisations included are for demonstration purposes only and do not disclose any sensitive or proprietary information.

## Business Problem

Commercial customer information was maintained across multiple spreadsheets and systems. This created several challenges:

- Duplicate reporting work across teams
- Manual copy-and-paste processes
- Inconsistent reporting figures
- Limited visibility of customer usage and agreement status
- Difficult audit preparation and data traceability

## Overview

This project redesigned how recycled water customer information was collected, structured and reported.

The project included redesigning source data structures and integrating customer, metering and operational data into Power BI reporting tools.

## Data

The project consolidates information from multiple systems:

- SharePoint Excel
- HiAffinity (Customer and Billing Database)
- Seeq (SCADA)
- Metering datasets

The dashboard identified unusual usage patterns which supported investigations into potential meter issues.
